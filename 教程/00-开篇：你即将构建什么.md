# 00 · 开篇：你即将亲手构建什么

> FocusPet 零基础开发教程 · 第 0 篇

## 这个项目是什么

一只住在你的 Mac 桌面上的小猫（或小狗）。它会：

- 在屏幕上**慢悠悠散步**（猫）或**蹦跳撒欢**（狗），偶尔全屏乱窜
- 你**按住拖动**它，它会挥手挣扎；松手落地弹一下
- 你**单击**它，它吃鱼/啃骨头；**双击**它，它开心地庆祝、飘爱心
- 你**开始专注**（番茄钟 25 分钟），它头顶出现倒计时时钟，安静看书
- 专注结束，它**跑到屏幕正中央**为你庆祝，然后提醒你休息
- 超过 2 小时没喂它，它会委屈地讨食；专注时它不打扰，只发一条通知
- 状态栏有它的图标，可以切猫切狗、看统计、改设置

这不是玩具demo，而是一个**完整发布的 macOS 应用**：有窗口系统、动画引擎、状态机、数据持久化、系统通知、开机自启、Release 构建。

## 核心思路（先建立直觉）

整个应用其实只回答三个问题：

1. **画什么**——一个透明窗口里，按时间顺序切换 8 张 PNG 图片（帧动画）
2. **什么时候画**——用「状态机 + 定时器」决定此刻该播哪套动画、该不该移动
3. **怎么记住**——UserDefaults 存设置，JSON 文件存专注记录

所有「智能」的行为（散步、讨食、庆祝）都是**随机数 + 计时器**的组合，没有 AI、没有机器学习。理解了这一点，你就不会被代码量吓到。

## 开发环境

- 一台 Mac（macOS 14+）
- Xcode 命令行工具：`xcode-select --install`（不用装完整的 Xcode）
- 验证：`swift --version` 能输出版本号即可

## 建议的学习方式

1. 先通读 01~03，建立整体地图
2. 然后**对照源码读**每一篇（教程里贴了关键代码和文件路径）
3. 每读完一篇，自己改一个小地方（改时长、改概率、改文案），跑起来看效果
4. 全部读完后，尝试「给宠物加第 3 只」——那是最好的毕业考试

源码位置：`FocusPet/Sources/FocusPet/` 下每个 `.swift` 文件对应一个类，文件名 = 类名，非常好找。
