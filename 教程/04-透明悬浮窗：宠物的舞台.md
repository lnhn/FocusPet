# 04 · 透明悬浮窗：宠物的舞台

> FocusPet 零基础开发教程 · 第 4 篇
> 对应源码：`PetController.swift` 的 `init`、`setScale`；`PetView.swift` 的 `petArea`、`draw`

## 1. 目标效果

一个**没有标题栏、没有背景色、永远浮在所有应用之上、点它不抢焦点**的小窗口，里面住着猫。这在 macOS 上的配方是：

```swift
panel = NSPanel(
    contentRect: frame,
    styleMask: [.borderless, .nonactivatingPanel],
    backing: .buffered,
    defer: false
)
panel.backgroundColor = .clear
panel.isOpaque = false
panel.level = .floating                 // 悬浮层级
panel.hasShadow = false                 // 阴影会有矩形轮廓，必须关
panel.collectionBehavior = [.canJoinAllSpaces, .fullScreenAuxiliary, .stationary]
panel.isFloatingPanel = true
panel.becomesKeyOnlyIfNeeded = true
```

逐个解释：

| 属性 | 为什么 |
|---|---|
| `.borderless` | 去掉标题栏/关闭按钮，窗口只剩"内容" |
| `.nonactivatingPanel` | 点宠物时菜单栏仍然是当前 app 的——不然点一下猫，你的代码编辑器就"失焦"了 |
| `.clear` 背景 | 窗口本身透明，只有画上去的猫可见 |
| `.floating` | 层级比普通窗口高，永远看得见 |
| `.canJoinAllSpaces` + `.stationary` | 切虚拟桌面/全屏时宠物不动、跟着走 |

## 2. 窗口布局：上下分区

窗口 200×240pt，下方正方形是宠物区，上方留给气泡：

```swift
private var petArea: NSRect {
    let side = min(bounds.width, bounds.height)
    return NSRect(x: 0, y: 0, width: bounds.width, height: side)
}
// 视图坐标系原点在左下：y=0 是底部
```

```
┌──────────┐ 240
│  倒计时气泡 │ ← drawBubble()
│  饥饿气泡  │ ← drawHungerBubble()（叠在倒计时上方）
├──────────┤
│          │
│   猫咪    │ ← petArea（200×200）
│          │
└──────────┘
```

## 3. 像素级透明：draw(_:) 的第一行

```swift
override func draw(_ dirtyRect: NSRect) {
    NSGraphicsContext.current?.cgContext.clear(dirtyRect)  // ★先清空成透明
    // ... 再画帧、气泡、爱心
}
```

`clear` 把指定区域重置为全透明。**不清空会怎样？** macOS 视图的默认行为是"保留上次绘制内容"，移动窗口或重绘时会留下上一帧的残影——这是我们项目早期最著名的 bug「拖影」的元凶之一。

## 4. 为什么不用 layer-backed 视图

PetView 的 init 里有一行注释值得记住：

```swift
// 刻意不用 wantsLayer：layer-backed 视图在透明窗口里高频重绘会有残影
```

Cocoa 视图默认是"直接绘制到窗口 backing store"；开 layer 后走 Core Animation 事务合成，在透明窗口 + 高频重绘的场景下会留下中间态残影。这是个"踩过才知道"的坑，记住结论即可：**透明窗口上的逐帧动画，保持非 layer 视图**。

## 5. 自适应缩放：一个公式适配所有窗口尺寸

宠物大小可调（50%~150%），窗口尺寸 = 200s × 240s。视图内部不硬编码任何坐标，全部用 `bounds` 和 `viewScale` 推导：

```swift
func setScale(_ scale: CGFloat) {
    let s = min(max(scale, 0.5), 1.5)
    petView.viewScale = s
    let newSize = NSSize(width: 200 * s, height: 240 * s)
    // 保持窗口中心点不变缩放（不是左上角锚定，宠物不会"跳"）
    let center = NSPoint(x: panel.frame.midX, y: panel.frame.midY)
    panel.setFrame(NSRect(x: center.x - newSize.width / 2, ...), display: true, animate: false)
    petView.frame = NSRect(origin: .zero, size: newSize)
}
```

视图里的气泡字号、内边距、尾巴偏移全部乘 `viewScale`——这就是"一处缩放、处处跟随"的写法。

## 6. 多屏与可见区域

乱窜和庆典移动都要知道"能飞多远"：

```swift
let visible = (panel.screen ?? NSScreen.main)?.visibleFrame
// visibleFrame = 屏幕减去 Dock 和菜单栏后的安全区域
```

注意用 `visibleFrame` 而不是 `frame`——否则宠物可能躲进 Dock 后面。

## 7. 验收清单：怎么验证一个透明悬浮窗做对了

| 测试 | 标准 |
|---|---|
| 显示 | 只有猫可见，无矩形背景 |
| 点击 | 猫响应，前台 app 不切换 |
| 全屏看视频 | 猫还在（不消失、不闪） |
| 切 Space | 猫留在原地 |
| 拖动 | 贴手，无延迟 |
| 明暗两种桌面壁纸 | 都无残影 |
