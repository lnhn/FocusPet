## 怎么读这套教程

- **按顺序读**：每篇只依赖前面的篇目，尤其 03（架构）是后面所有篇的地图。
- **对着源码读**：每篇开头标注了对应源码文件，先读教程讲解，再打开源码逐行对照——教程里贴的每一行代码都真实存在于项目中。
- **做每篇末尾的练习**：练习不是点缀，是「从看懂到会用」的唯一通道。每个练习都能在 30 分钟内完成。
- **随时跑起来**：`swift run` 一秒钟看到效果，改一行代码立刻看到变化——这个项目最大的优点是反馈极快。

## 几句心里话

这个项目从「能不能做个桌面宠物」的一句话，到上架 /Applications 的完整应用，全程没有一行代码是从模板里抄的——每个类、每个函数都是需求驱动、踩坑修正长出来的。这套教程记录的不仅是「怎么写」，更是「为什么这么写」：每一句注释里的教训（残影、漂移、点击无响应、透明洞），都来自真实发生过的故障。

编程最好的教材不是语法书，而是**一个你能完全看懂的、真实运转的程序**。现在你有它了。
